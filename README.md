# Sorry, I Heard That Wrong

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-kiencx-sorry-i-heard-that-wrong-1858c729)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Entry for the [make.fun bounty "Sorry, I Heard That Wrong"](https://make.fun/bounty/u-kiencx-sorry-i-heard-that-wrong-1858c729): a single line (at most 140 characters) — the apology a smart speaker gives its owner after it mishears them.

`main.py` (Python stdlib only) writes the line to `/output/entry.txt`.

## Entry

> Sorry, I heard 'play something chill' as 'buy a chinchilla,' so one is en route. Order cancelled — your playlist is ready.
